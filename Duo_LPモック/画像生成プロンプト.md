# 画像生成プロンプト（NXTERA LPモック用）

モック内の「撮影指示」を、画像生成AI（ChatGPT / GPT Image）に渡せる形にしたもの。
生成後は下表のサイズに書き出して、モックの `.shot__fig`（インラインSVG）と差し替える前提。

**現在は飲食店版（02）のみ。理美容版（03）は着手時に作る。**

## 納品サイズ（飲食店版）

| # | 用途 | 生成サイズ | 切り抜き | 最終サイズ |
|---|---|---|---|---|
| A-2 | 02 飲食LP・PC右カラム【採用】 | **1024 × 1536**（縦長2:3） | **不要**。そのまま渡す | 880 × 1320 |
| A | 02 飲食LP・PC右カラム（旧・横位置） | 1536 × 1024（横長3:2） | 不要 | 1000 × 667 |
| B | 02 飲食LP・スマホ用（予備） | **1536 × 1024**（横長3:2） | 中央を横長に切り抜き | 750 × 280 |

**A は切り抜き不要。** 画像生成AIが出せる横長は 1536×1024（3:2）で 4:3 は直接出せないため、
モック側の枠を 3:2 に合わせる方針にした（差し替え時に `.shot__fig` の viewBox を調整する）。
生成した画像をそのまま渡せばよい。

- 形式は WebP（品質80前後）／JPEG可。最終的に 150KB 以下を目安に圧縮する。
- **拡大（アップスケール）はしない。** 小さく出たら作り直す。
- B は現在モックに枠がない予備。使う場合は `.shot` のSP表示を有効にする必要がある。

## A：02 飲食LP・PC右カラム（本命）

元の撮影指示：
> 営業後の店内でスマホを見るオーナー。
> 構図：カウンター席に一人。手前に締め作業中の伝票とレジ、奥に消灯した客席。人物は胸から上を画面右に寄せ、左に文字スペースを空ける。
> 光：暖色の残照＋スマホの明かり。強い影を作らない。
> 避ける：作り込んだ笑顔、真正面、料理の寄り。

```
日本の小さな居酒屋の、閉店後の店内を撮った写真。

木のカウンターに店主が一人。胸から上だけが写り、画面の右3分の1に寄っている。
体は斜めに向けてカメラから顔をそらし、手元のスマートフォンを見下ろしている。
顔は見えない。

手前のカウンターの上には、締め作業の途中の伝票の束、小さな電卓、古い型のレジ。
奥には、照明を落とした客席が柔らかい影の中に沈んでいる。
画面の左半分は、あとから文字を載せられるように、あえて何も置かず静かにしておく。

光：ペンダントライト1灯の暖かい残り灯と、手元を照らすスマートフォンの冷たい光。
影は柔らかく、強い影やフラッシュの光は作らない。

雰囲気：静かで、長い一日が終わったあとの記録写真。広告写真にはしない。
色：彩度を抑えた暖色。茶色と琥珀色が基調。

35mmレンズ、手持ちの自然な構え。被写界深度は浅めだが、極端にはぼかさない。実写。

入れないもの：文字・看板・ロゴ・メニューなどの文字情報／見えている顔やカメラ目線／
作り笑顔やポーズ／正面からのポートレート／料理の寄り／鮮やかで彩度の高い色／
欧米風のバーやパブの内装。

画像サイズ：1536 × 1024 ピクセル（横長・3:2）。この比率と解像度で1枚生成してください。
```

**切り抜き不要。** 生成された 1536×1024 をそのまま使う。
人物が右3分の1、左が空いた状態になっているかだけ確認すること。

## A-2：02 飲食LP・PC右カラム【縦位置版・採用済み】

**この版を採用済み。** 横位置版はキャプションを外したあと右カラムに縦の余白が残るため、
縦構図に差し替えた。左の文字カラムとほぼ同じ高さになり、余白の振り分けが不要になった。

### 空席は主役にしない

「閉店後」を伝えているのは、実は伝票の束と電卓（＝締め作業）であって空席ではない。
そして**空席を大きく見せると「閉店後の静けさ」ではなく「客が来ていない店」に読める**。
読者は集客に悩んでいるオーナーで、キャッチも「今月、席が埋まらなかった曜日はどこですか。」。
そこに空席を大写しにすると、痛いところを突くのを越えて責めているように見える。

採用画像は空席が見えてはいるが、主題は右側の店主と手元にあり、この条件を満たしている。
作り直す場合は、下のプロンプトのように**主役を手元に置き、奥は暗く落とす**こと。

```
日本の小さな居酒屋のカウンターを、閉店後に縦位置で撮った写真。

主役は手元。画面の下半分に、木のカウンターの上の締め作業が大きく写っている。
伝票の束、小さな電卓、ボールペン、書きかけの帳面、湯呑み。
その少し奥、画面の中ほどやや右に、店主が一人。胸から上だけが写り、
体は斜めに向けてカメラから顔をそらし、手元のスマートフォンを見下ろしている。
顔は見えない。すぐ脇に古い型のレジ。

画面の上のほう、店主の背後には、照明を落とした店内が暗く沈んでいる。
長いカウンターが奥へ伸び、その先はぼやけて輪郭がはっきりしない。
天井のペンダントライトが一灯だけ、ぼんやりと光っている。
手前が明るく、奥へ向かって暗くなる。

光：ペンダントライト1灯の暖かい残り灯と、手元を照らすスマートフォンの冷たい光。
影は柔らかく、強い影やフラッシュの光は作らない。

雰囲気：静かで、長い一日が終わったあとの記録写真。広告写真にはしない。
色：彩度を抑えた暖色。茶色と琥珀色が基調。

35mmレンズ、少し高い位置から手元を見下ろす角度。手前にピント、奥は大きくぼかす。実写。

入れないもの：文字・看板・ロゴ・メニューなどの文字情報／見えている顔やカメラ目線／
作り笑顔やポーズ／正面からのポートレート／料理の寄り／鮮やかで彩度の高い色／
欧米風のバーやパブの内装／がらんとした客席が画面の主役になっている構図。

画像サイズ：1024 × 1536 ピクセル（縦長・2:3）。この比率と解像度で1枚生成してください。
```

**切り抜き不要。** 1024×1536 をそのまま渡せば、880×1320（440px表示の2x）に書き出して組み込む。

### 確認すること
1. **手元（伝票・電卓）が読み取れる大きさか。** 小さいと、ただの人物写真になる
2. **空席が画面の主役になっていないか**
3. 文字が写り込んでいないか／顔が見えていないか

## 生成後の確認（飲食店版）

1. **左半分が空いているか**（A）— 人物が中央に来がち。ここが埋まるとキャッチが乗らない
2. **文字が写り込んでいないか** — 看板、ボトルのラベル、メニュー、レジの表示
3. **顔・カメラ目線・作り笑顔がないか**
4. **日本の小規模店舗に見えるか** — 放っておくと欧米的な広いバーになる
5. 彩度が上がりすぎていないか（モックのトーンは「静か・実務・対等」）

1・2・4 は生成AIが最も外しやすい。ここだけは毎回見ること。

## C：03 理美容LP・PC右カラム【縦位置版】

飲食（A-2）と同じ設計。**縦構図で、主役は手元。** PC右カラムにのみ表示する。

### 空席・空いた席を主役にしない

飲食と同じ理由。「閉店後の静けさ」を伝えているのは**締め作業の手元**であって、
誰も座っていないセット面ではない。空のチェアを大きく見せると
「客が来ていないサロン」に読め、集客に悩む読者を責めているように見える。
→ **奥は暗く落として気配だけ。** ピントも当てない。

### 飲食との違い（トーンを揃えないこと）
飲食は炭火の赤茶で暖色。**理美容はくすんだ青灰（#46707F）で、清潔感と洗練**。
同じ「閉店後」でも、**光の色を暖色ではなくニュートラル〜寒色**に寄せる。
垂直・水平の線を効かせて、飲食より静かに見せる。

```
日本の小さな美容室を、閉店後に縦位置で撮った写真。

主役は手元。画面の下半分に、セット面のカウンターの上が大きく写っている。
開いた予約台帳かタブレット、顧客カルテの束、ペン、はさみとコームが
きちんと並べて置かれている。

その少し奥、画面の中ほどやや右に、スタッフが一人。胸から上だけが写り、
体は斜めに向けてカメラから顔をそらし、手元の台帳かタブレットを見下ろしている。
顔は見えない。エプロンかシャツは黒か濃紺。

画面の上のほう、その背後には、照明を落とした店内が暗く沈んでいる。
大きな鏡と、その上の細いライトバーが1本だけ光っている。
奥に何があるかは、はっきりとは分からない。ピントは合っておらず、輪郭がぼやけている。
手前が明るく、奥へ向かって暗くなる。

光：鏡の上のライトバーだけが点いている。白に近いニュートラルな光で、
手元を静かに照らしている。暖色のオレンジみは強く出さない。
影は柔らかく、強い影やフラッシュの光は作らない。

雰囲気：清潔で、静かで、一日が終わったあとの記録写真。広告写真にはしない。
色：彩度を抑えたニュートラル〜寒色。白、淡いグレー、くすんだ青灰が基調。

35mmレンズ、少し高い位置から手元を見下ろす角度。垂直と水平の線をまっすぐに出す。
手前にピント、奥は大きくぼかす。実写。

入れないもの：文字・看板・商品ラベル・ブランド名などの文字情報／
見えている顔やカメラ目線／作り笑顔やポーズ／正面からのポートレート／
施術中のビフォーアフター／鮮やかで彩度の高い色／欧米風の広いスパの内装／
誰も座っていないチェアが画面の主役になっている構図。

画像サイズ：1024 × 1536 ピクセル（縦長・2:3）。この比率と解像度で1枚生成してください。
```

**切り抜き不要。** 1024×1536 をそのまま渡せば、880×1320（440px表示の2x）に
書き出して組み込む。飲食と同じく、枠側を 2:3 に変更する。

### 確認すること
1. **手元（予約台帳・カルテ・はさみ）が読み取れる大きさか**
2. **奥がぼけて暗く落ちているか。** 空のチェアがはっきり写っていたら作り直す
3. **光が暖色に寄りすぎていないか。** 飲食と同じ色味になると、2枚並べたときに差が出ない
4. 文字が写り込んでいないか／顔が見えていないか

## D：01 統合版LP・PC右カラム【縦位置・業種を特定しない1枚】

01は「MEO 集客」のような**業種を含まない一般クエリ**の受け皿。
飲食・理美容の写真を2枚並べていたが、1枚にまとめる。

### 唯一の条件：業種が分からないこと

居酒屋と美容室を同じフレームに入れることはできないので、
**どちらのオーナーが見ても自分に見える場面**を撮る。鍵は小物の選別。

| 入れない（業種が割れる） | 入れる（どの店にもある） |
|---|---|
| 料理・食器・酒瓶・ジョッキ | レジ |
| はさみ・コーム・鏡・シャンプー台 | 伝票・売上帳・レシートの束 |
| メニュー表・スタイルブック | 電卓、スマートフォン |
| 施術チェア、カウンター席の並び | ペン、ノート |

光も中立にする。飲食（暖色）と理美容（寒色）の中間で、
統合版のアクセントであるブランドの墨緑に馴染む色温度にする。

```
日本の小さな個人店を、閉店後に縦位置で撮った写真。

主役は手元。画面の下半分に、カウンターの上の締め作業が大きく写っている。
レシートと伝票の束、小さな電卓、ボールペン、書きかけの帳面、古い型のレジ。
店の種類が分かるものは何も置かれていない。

その少し奥、画面の中ほどやや右に、店主が一人。胸から上だけが写り、
体は斜めに向けてカメラから顔をそらし、手元のスマートフォンを見下ろしている。
顔は見えない。黒か濃紺のシャツかエプロン。

画面の上のほう、その背後には、照明を落とした店内が暗く沈んでいる。
何の店かは、はっきりとは分からない。ピントは合っておらず、輪郭がぼやけている。
天井の照明が一灯だけ、ぼんやりと光っている。
手前が明るく、奥へ向かって暗くなる。

光：白とわずかな電球色の中間。暖かすぎず、冷たすぎない。
影は柔らかく、強い影やフラッシュの光は作らない。

雰囲気：静かで、長い一日が終わったあとの記録写真。広告写真にはしない。
色：彩度を抑えたニュートラル。木の色、グレー、生成りが基調。

35mmレンズ、少し高い位置から手元を見下ろす角度。手前にピント、奥は大きくぼかす。実写。

入れないもの：文字・看板・ロゴ・メニューなどの文字情報／見えている顔やカメラ目線／
作り笑顔やポーズ／正面からのポートレート／
料理・食器・酒瓶・ジョッキ／はさみ・コーム・鏡・シャンプー台・施術チェア／
商品の陳列棚／鮮やかで彩度の高い色／欧米風の内装／
がらんとした客席が画面の主役になっている構図。

画像サイズ：1024 × 1536 ピクセル（縦長・2:3）。この比率と解像度で1枚生成してください。
```

**切り抜き不要。** 1024×1536 をそのまま渡せば、880×1320（PC用）と
800×533（スマホ用の横長）に書き出して組み込む。**スマホ用の追加生成は不要。**

### 確認すること
1. **何屋か分からないか。** ここが最重要。料理や美容の道具が1つでも写っていたら作り直す
2. **手元（伝票・電卓・レジ）が読み取れる大きさか**
3. **光が暖色にも寒色にも寄りすぎていないか。** 02・03と並べたとき、その中間に見えるのが正解
4. 文字が写り込んでいないか／顔が見えていないか

## E：05 資金繰りLP・PC右カラム【縦位置・向かい合う2人／顔は出さない】※E-2に差し替え済み・未使用

05は担当者カードを「支援の範囲」の下（CTAの真上）へ移したため、FV上部が文字だけになる。
そこを埋める1枚。**特定の個人を写さない**ことが前提。05は担当者を個人ではなく体制として
見せる方針なので（README 4-2）、この写真も「担当者の紹介」ではなく「相談している場面」を撮る。

### この1枚が満たすこと

| 条件 | 理由 |
|---|---|
| **顔を写さない** | 個人を出さない方針のため。内容によって複数名で対応する可能性があり、担当個人の顔は見た人の好みで失注要因にもなる。顔が写った時点で「この人が担当します」という約束になってしまう |
| **2人いる** | 05の重心は「絵より人」。ひとりで悩んでいる絵ではなく、**誰かと一緒に見ている**絵にする |
| **業種が分からない** | 資金繰りは3領域横断。飲食のオーナーにもサロンのオーナーにも自分に見える必要がある。小物の選別は D（01）と同じ |
| **銀行の窓口に見えない** | スーツ・カウンター・応接セットは入れない。あくまで**閉店後の店のテーブル**。金融機関の人間だと誤読させない |
| **光を立てない** | 02のような斜光の演出はしない（05は装飾を一段落としている）。平らで静かな光 |

キャッチ「月末が近づくたび、通帳を見に行っていませんか。」を受けるので、
**手元の主役は通帳サイズの小冊子と、手書きの表**。ただし文字は読ませない。

```
日本の小さな個人店を、閉店後に縦位置で撮った写真。

画面の下半分が主役。店のテーブルの上に、手書きの表が1枚広げてある。
罫線に沿って数字らしきものが並んでいるが、文字は小さく、読み取れない。
その横に、通帳くらいの大きさの薄い小冊子、電卓、ボールペン、湯呑みがひとつ。

テーブルをはさんで2人。どちらも胸から下だけが写っていて、顔は見えない。
手前の一人は椅子に浅く座り、片手を表の上に置いている。濃い色のエプロン。
向かい側の一人は少し前かがみになり、人差し指で表の一行を指している。
濃紺のシャツ。袖は肘までまくってある。スーツは着ていない。
2人とも同じ紙を見ている。

画面の上のほう、その背後は、照明を落とした店内が暗く沈んでいる。
何の店かは、はっきりとは分からない。ピントは合っておらず、輪郭がぼやけている。

光：白色に近く、わずかに冷たい。天井からの平らな光で、斜めから差す強い光は作らない。
影は薄く、テーブルの上にほとんど落ちない。

雰囲気：静かで、事務的。相談が始まって少し経ったところ。
励ましでも売り込みでもなく、2人で同じ紙を見ている時間。記録写真の温度で。
色：彩度を抑えたニュートラル。濃紺、グレー、木の色、生成りが基調。
```
