# 01 集客LP 改修メモ

確認日：2026-09-17。これは制作・公開準備用の資料で、LPには掲載しません。

## 立ち位置

対象はMEO等の依頼先比較だけでなく、集客不振の原因や次の手段がまだ分からない店舗オーナー。
「予算も時間も無駄にしたくない。自店で変えるところを見極め、実行も相談したい」をインサイト仮説とする。
実行範囲は事業者による確認が必要。無制限な代行、店舗経営全体の改善、成果保証を意味しない。

## 公式サイト比較

- [MEO Dash! byGMO](https://meo-dash.com/lp/)：MEO施策、キーワード数別料金、事例、資料請求。施策の比較検討向けの明快さを参考にした。
- [MEO HATCH byGMO](https://meo.tryhatch.co.jp/lp/)：運用作業、店舗側の協力、広告支援、料金・契約期間を掲載。「全部任せられる」と誤認させない役割分担を参考にした。前者と同じGMO系。
- [カンリー](https://jp.can-ly.com/)：多店舗情報・口コミの一括管理と分析・サポート。個店向け伴走とは対象が異なるが、具体的な業務・画面を示す点を参考にした。
- [ALUTE 店舗集客改善サポート](https://alute.co.jp/store_support/)：店舗の現状・優先順位から運用を組み立て、診断・月額支援・別途制作を区別。媒体横断や優先順位だけでは独自性にならないことを確認した。
- [matoka](https://matoka.co.jp/)：飲食店に特化しMEO・SNS・Web等の支援と事例を提示。業種別の理解を具体例で示す重要性を参考にした。
- [favy 店舗掲載案内](https://info.favy.jp/pg/LP03.html)：メディア掲載に加え、予約・顧客管理・集客相談等を案内。単なるMEO以外の競合・選択肢もあることを確認した。

競合の掲載実績は各社の自己申告で、効果は独立検証していない。競合価格をNXTERAの価格根拠にしたり、競合の強みを自社実績として転用したりしていない。

- [食べログ公式 平日集客](https://owner-blog.tabelog.com/hansoku-syukyaku/post-45.html)：曜日・対象客等を分けて考える参考。
- [Google ローカル順位](https://support.google.com/business/answer/7091?hl=ja)：関連性・距離・知名度等。上位表示の保証はしない。
- [Google 投稿ポリシー](https://support.google.com/contributionpolicy/answer/7400114?hl=ja)：実体験・任意の投稿、報酬付き投稿や肯定的口コミだけを募る運用の禁止。

## 公開前に確定すること

1. 対応業種・地域・相談方法・相談料・所要時間・受付枠。
2. 提案と実行代行の範囲、媒体、投稿・返信回数、制作物、担当・承認フロー。
3. 初期費用、月額、税込総額、広告費・外部ツール費、最低期間、解約と返却条件。
4. 運営法人、問い合わせ先、担当体制、掲載可能な支援実績。未確認の人数・経験・資格は足さない。
5. 権限付与方法、データの利用目的・保管・委託・削除、正式なプライバシーポリシー。
6. 本番予約受付と完了計測。モックの予約ページを実受付と誤認させない。

## 広告検証

悩み探索・方法探索・依頼先比較を分け、広告文と冒頭を合わせる。すべての検索を一律に出稿対象としない。
実検索語句と相談内容から対象外の意図を確認し、必要なら除外語や専用LPを設ける。
相談CTAのクリック、予約完了、有効相談、契約を別々に測定する。流入元・費用と照合し、クリック率だけでは判断しない。
本改修では広告配信・課金・計測タグ追加・クエリ別出し分けは行わない。
